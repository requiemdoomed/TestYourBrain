# Networking Basics

## The OSI Model
The OSI model has seven layers: physical, data link, network, transport, session, presentation and application.
The network layer is responsible for routing packets between different networks.

## TCP and UDP
TCP is a connection-oriented protocol that guarantees reliable, ordered delivery.
UDP is a connectionless protocol with lower overhead but no delivery guarantees.
TCP establishes a connection using a three-way handshake of SYN, SYN-ACK and ACK.

## DNS
The Domain Name System translates human-readable domain names into IP addresses.
DNS queries normally use UDP on port 53.
